# Prospective Phase 13 statistical-analysis plan

Freeze task inclusion, outcomes and analysis before evaluation access. Binary paired outcomes may use
McNemar only after discordant-pair assumptions are checked, plus paired task-cluster bootstrap intervals
and paired proportion difference or matched odds ratio. Continuous/ordinal paired outcomes may use
Wilcoxon signed-rank only after symmetry/tie suitability checks, paired bootstrap intervals and
rank-biserial effect size. Repeated runs require task clustering and, if justified, hierarchical or
mixed-effects models with provider/model as explicit factors. Confirmatory families use Holm correction.
Report effect sizes, uncertainty, raw denominators, corrected and uncorrected p-values, practical
significance and missing-data sensitivities. Phase 12 applies no confirmatory test.
