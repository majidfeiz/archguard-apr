# Experiment plan

`archguard.experiment-plan/v1` binds benchmark snapshot, frozen split and profiles, system/provider
configuration, prompt and execution versions, seed, budgets, repetitions, baselines, ablations, metric
specification, relative output directory and resume policy. Credentials are prohibited. Final plans
fail validation unless evaluation tasks and profiles are frozen. Provider prices require a dated table;
missing usage remains missing. Plans and amendments are registered before outcome inspection.
