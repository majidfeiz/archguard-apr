# Benchmark licensing register

Phase 11 redistributes no external benchmark source or dataset. The controlled ArchGuard fixture is
Apache-2.0 and points to this repository's license. BugsInPy and SWE-bench framework/dataset metadata,
plus every upstream project license, must be verified from the official source at acquisition time.
Framework licensing never overrides an upstream project's terms. Record copyright notices, repository
and dataset URLs, access date, modification and redistribution status. Unclear status is `unresolved`,
requires legal review, and excludes the task from release artifacts. Automated detection is not legal
advice. Exact external license conclusions are intentionally not asserted here because acquisition was
not performed.
