# Comparison Contract v1

`archguard.comparison-contract/v1` is immutable canonical metadata binding the benchmark/split,
source-free references, tasks, C0–C6 configurations, repetition/seed/order, resource controls, missing
and cost policies, evaluator tests and hardware class. Its SHA-256 semantic fingerprint excludes
calendar time, host paths and runtime IDs. Unknown fields and mismatched fingerprints fail closed.
