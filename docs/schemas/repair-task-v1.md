# Repair task v1

`archguard.repair-task/v1` binds an immutable task ID and baseline revision to source-free profile,
graph and execution-plan references; untrusted problem/test identifiers; strict path and patch bounds;
round/candidate/provider/validation/unit budgets; provider/diversity policy; mandatory acceptance gates;
and human approval policy. Absolute/traversal paths, unsupported versions, unbounded or contradictory
budgets, missing references, model-evidence trust, and disabled validation fail closed.
