# ADR-0021: License, graph, and pilot evidence boundaries

Status: Accepted for Phase 12.8A preparation.

License scope is recorded independently for frameworks, datasets, and upstream projects. Missing text is
unresolved. Graph evidence is source-free and revision/profile-bound. Candidate selection uses only
prespecified metadata and cannot replace failed tasks. A 4–6-task pilot establishes feasibility only;
final readiness continues to require a separately frozen, adequately powered population and human review.
