# Repository publication checklist

- [x] Baseline, Phase 13 closure, manuscripts, package version, and publication hashes inspected.
- [x] Current tree and reachable history scanned without printing values.
- [x] Public README, citation metadata, governance, license scopes, artifact policy, and release drafts prepared.
- [x] Provider requests, experiments, external benchmarks, Docker workloads, tags, releases, and visibility changes avoided.
- [ ] Resolve or explicitly accept the reachable-history private-email disclosure.
- [ ] Obtain human/legal review of benchmark metadata and third-party redistribution assumptions.
- [ ] Enable private vulnerability reporting, secret scanning, push protection, Dependabot, and protected `main` settings.
- [ ] Review and pin sensitive third-party Actions by immutable commit where practical.
- [ ] Replace release-version placeholder only when a release is approved.
- [ ] Review the GitHub-generated source archive and Zenodo deposit before publication.
- [ ] Make the repository public only after `public-release-gate.json` is regenerated as `READY_FOR_PUBLICATION`.
