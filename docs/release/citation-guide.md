# Citation guide

The preferred citation is currently the software repository described by [`CITATION.cff`](../../CITATION.cff), version 0.12.8. No DOI, venue, peer-review status, or archival publication is claimed.

GitHub's “Cite this repository” function may render the CFF metadata. Verify the author name, ORCID, affiliation, version, repository URL, and public email before every release.

After a genuine Zenodo deposit: verify the public record and DOI, add only the assigned DOI to CFF, add the archived release as an identifier, and decide whether the software record or a DOI-backed manuscript becomes `preferred-citation`. Never use a draft, reserved, or guessed DOI. Keep software and manuscript versions distinguishable.
