stored here. Never add downloaded ZIPs, extracted repositories, source, patches, gold/evaluator
material, or raw logs.

strict Phase 12.8F importer. The retained archive hash and GitHub run identifier bind each import;
downloaded archives and extracted artifact members remain outside the repository.
